HOW TO USE THIS CATALOG
================================================================================

FOR CALCULATOR DEVELOPERS:
  1. Start with CUTTING_DATA_COMPILED.json
  2. Import material/operation data structure
  3. Implement basic RPM/feed calculations
  4. Add adjustment factors from formulas section
  5. Reference MANUFACTURER_DATA_CATALOG.md for additional context
  6. Use confidence scores for warning/validation logic

FOR MACHINE OPERATORS:
  1. Find material in MANUFACTURER_DATA_CATALOG.md
  2. Look up operation and tool type
  3. Read cutting speed (SFM) range
  4. Calculate RPM using formula: RPM = (SFM × 3.82) / Diameter
  5. Check feed rate (IPT) for your tool
  6. Start conservative, increase gradually

FOR TOOL MANUFACTURERS:
  1. Compare your data against consensus values
  2. Check MANUFACTURER_RESOURCES_INDEX.md for competitor sources
  3. Validate your formulas against standard equations
  4. Update your own recommendations if needed
