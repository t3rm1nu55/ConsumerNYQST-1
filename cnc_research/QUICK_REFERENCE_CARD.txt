╔══════════════════════════════════════════════════════════════════════════════╗
║                        ESSENTIAL FORMULAS                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

  SPINDLE SPEED (RPM):
    RPM = (SFM × 3.82) / Diameter_inches
    
    Example: 500 SFM, 0.5" diameter
    RPM = (500 × 3.82) / 0.5 = 3,820 RPM

  FEED RATE (IPM):
    Feed_IPM = IPT × Flutes × RPM
    
    Example: 0.015 IPT, 4 flutes, 3,820 RPM
    Feed = 0.015 × 4 × 3,820 = 229 IPM

  METRIC (RPM):
    RPM = (1000 × Vc_m/min) / (π × Diameter_mm)

╚══════════════════════════════════════════════════════════════════════════════╝

  HARDNESS (vs. baseline at 150 HB):
    <150 HB:    ×1.1  (softer materials)
    150-200:    ×1.0  (baseline)
    200-250:    ×0.85
    250-300:    ×0.65
    >300 HB:    ×0.30 (very hard, use ceramic)

  COOLANT CONDITION:
    Dry:        -15% speed
    Minimal:    -5% speed
    Wet:        1.0× (baseline)
    High-pressure: +15% speed

  TOOL CONDITION:
    New/sharp:  +10% speed
    Normal:     1.0× (baseline)
    Worn:       -30% speed

  MACHINE RIGIDITY:
    Rigid:      +15% possible
    Medium:     1.0× (baseline)
    Light:      -25% reduction

╚══════════════════════════════════════════════════════════════════════════════╝

╔══════════════════════════════════════════════════════════════════════════════╗
║                        TROUBLESHOOTING                                       ║
╚══════════════════════════════════════════════════════════════════════════════╝

  TOOL BREAKING:          Reduce feed, check runout, increase coolant
  POOR FINISH:            Increase speed, reduce feed, sharpen tool
  WORK HARDENING:         Increase speed (aluminum, stainless)
  BUILT-UP EDGE:          Increase speed or feed, use coolant
  CHATTER/VIBRATION:      Reduce depth, reduce speed, check setup
  THERMAL WEAR:           Reduce speed, improve coolant, check geometry

╔══════════════════════════════════════════════════════════════════════════════╗
║                      STARTING PARAMETERS (SAFE)                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

  For Unknown Material: Start at 200-250 SFM
  Carbide tools: Start conservative, increase by 10-15% increments
  When in doubt: Reference tool manufacturer spec sheet
  Key rule: Better to run slow than break tool
