## Data Extraction Workflow

### Step 1: Verify Source Availability
- [ ] Check if URL is still active
- [ ] Confirm data type (PDF, web page, calculator, API)
- [ ] Verify authentication requirements

### Step 2: Extract Material Data
- [ ] Material group name
- [ ] Hardness range (if available)
- [ ] Cutting speeds (SFM for multiple tool types)
- [ ] Feed rates (IPT or IPR)
- [ ] Special notes (work hardening, heat resistance, etc.)

### Step 3: Extract Operation Data
- [ ] Operation type (milling, turning, drilling)
- [ ] Depth of cut recommendations
- [ ] Speed adjustments for conditions
- [ ] Tool specifications
- [ ] Warnings or special requirements

### Step 4: Validate Against Multiple Sources
- [ ] Cross-reference with at least 2 manufacturers
- [ ] Check for consistency (±15% tolerance acceptable)
- [ ] Note any significant deviations
- [ ] Flag uncertain values for verification

### Step 5: Document Source & Confidence
- [ ] Primary source (manufacturer, publication)
- [ ] Date data was accessed
- [ ] Confidence level (high, medium, low)
- [ ] Any caveats or limitations

## Data Quality Metrics

### Scoring System for Each Material/Operation Combination

**High Confidence (Score 9-10):**
- Confirmed by 3+ manufacturers
- Supported by academic research
- Actively used in production
- Minimal variance across sources

**Medium Confidence (Score 5-8):**
- Confirmed by 2 manufacturers
- Some variance in recommendations
- Specific conditions may apply
- User adjustment likely needed

**Low Confidence (Score 1-4):**
- Single source only
- Specialty material
- Limited real-world use data
- Significant variance noted
- Requires experimental validation

## Troubleshooting Data Discrepancies

### If manufacturer data conflicts:

1. **Identify all sources** providing different values
2. **Check tool life assumptions** - different baseline = different speeds
3. **Verify coolant condition** - wet vs dry can vary by 20%+
4. **Consider coating/geometry** - specified tool type may differ
5. **Check publication date** - older data may be less aggressive
6. **Use consensus value** - average of multiple sources when conflict exists
7. **Note uncertainty** - mark data with confidence level for calculator users

### Example Conflict Resolution
```
Material: Aluminum 6061, Face Milling, Carbide
Source A (Haas): 500 SFM
Source B (Sandvik): 450 SFM
Source C (Harvey): 550 SFM
Resolution: Use 500 SFM (Haas) as primary, note range 450-550, confidence MEDIUM
```
